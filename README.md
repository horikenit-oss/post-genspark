# post-genspark

GenSpark代替スキル集。検索→比較→まとめ→提案を自己成長型で実装。

## スキル一覧
- `skills/product-comparison/` — 商品比較
- `skills/travel-planning/` — 旅行プランニング
- `skills/service-selection/` — サービス選定

## バージョン管理
各スキルは `versions/vX.Y.Z.md` で履歴管理。
改善ログは `logs/` に蓄積。

## 改善ループ
① お題生成 → ② スキル実行 → ③ GenSpark比較 → ④ 差分特定 → ⑤ スキル書き換え → ⑥ バージョンアップ → ①
