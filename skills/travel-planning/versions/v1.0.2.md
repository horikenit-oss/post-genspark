# 旅行プランニングスキル

## トリガー
「〇〇旅行プラン」「〇〇に行きたい」「〇〇観光 おすすめ」+日程・人数・予算・出発地・テーマ

## 実行プロセス

### Step 0: テーマ固有の重要軸を先に設定
例（紅葉）:「①特別拝観が重なる最適な日程 ②ライトアップとの組み合わせ ③混雑を避ける時間帯」

### Step 0.5: 予算の現実チェック（NEW）
予算に対して「普通に組むと超えやすいか」を最初に評価する。
- 超えやすい場合: 「普通に組むと¥X超えやすいです」と冒頭で言い、**最小コスト構成**を先に提案する
  例: 「那覇拠点+レンタカー1日だけ」「有料施設は2か所に絞る」
- 余裕がある場合: 通常プランで問題なし

### Step 1: 条件分解
- 目的地・出発地・日程（泊数）
- 人数・続柄（カップル・家族・友人等）
- 予算（交通費込み/別）
- テーマ（グルメ・自然・文化・アクティビティ等）
- 時期（混雑・気候・イベント）

### Step 2: 最適な旅行時期を特定する（NEW・最重要）
時期が未定の場合、または「秋の紅葉」「春の桜」等の季節指定がある場合:
- 主要スポットの**特別拝観・ライトアップ・イベント期間**を公式サイトで確認
- 複数スポットの期間が**最も重なる日程**を特定して明示する
- 例: 「清水寺ライトアップ(11/21-30)×永観堂ライトアップ(11/15-12/10)×天龍寺早朝(11/14-30)が全部入る11月21〜30日がベスト」

### Step 2.5: 観光施設の子供料金・年齢無料を確認（NEW）
子供がいる場合、主要施設の以下を公式サイトで確認して費用計算に反映する:
- 子供料金（何歳から有料か）
- 無料になる年齢上限
- 夏季・特別期間の営業時間延長の有無
これらを費用シミュレーションに正確に組み込む。

### Step 3: 検索クエリ設計（並列実行）
1. `[目的地] [主要スポット] 拝観時間 公式 [イベント期間]`
2. `[出発地] [目的地] 新幹線/交通 料金 公式` （JR公式・スマートEX）
3. `[目的地] ホテル 相場 [最適時期] [宿泊エリア]`
4. `[目的地] [テーマ] モデルコース [泊数] [最適月]`
5. `[目的地] 市内交通 1日券 料金 路線`

### Step 4: 動線の最適化（重要）
旅程の順序を以下の原則で組む:
- **到着日**: 宿泊地（駅）に近いエリアから入る（荷物あり）
- **混雑スポット**: 最終日の朝一番か、出発が早い日の午前に配置
- **ライトアップ**: その日の昼観光と同じエリアか隣接エリアに配置（移動最小化）
- **各スポットの具体的な交通手段と路線番号**を明記

### Step 5: 費用の内訳（1日別も出す）
2名合計の全体内訳:
| 項目 | 金額 | 備考 |
|------|------|------|
| 交通費（往復×2人） | ¥X | [手段・割引方法] |
| 宿泊費 | ¥X | ¥X/泊×2泊 |
| 市内交通 | ¥X | 1日券¥X×日数×2人 |
| 食事 | ¥X | 1日¥X/人×日数×2人 |
| カフェ・甘味 | ¥X | 旅先消費として計上 |
| 拝観・入場料 | ¥X | 主要スポット合算 |
| お土産・予備費 | ¥X | |
| **合計** | **¥X** | 予算¥X以内○/✗ |

+ 各Dayの予算目安も明示する

### Step 5.5: 類似施設のA案/B案比較（NEW）
同カテゴリで複数の施設がある場合（水族館・テーマパーク等）、A案/B案として比較して提示する。
- A案: コスパ重視 / B案: 体験重視 など
- 「どんな状況ならA/B」という判断基準も明示する

### Step 6: 日程表（Day別）
各Dayに:
- 朝〜昼: スポット名（交通手段と路線名・駅名・所要時間）
- 混雑回避のコツ（開門時間・入場方法・事前予約の要否）
- 昼食: 具体的なエリアや推薦ジャンル
- 午後〜夜: スポット + ライトアップ情報（公式確認済みの時間帯）
- 宿泊: 推薦エリアと理由

### Step 7: 予算節約コツ（NEW）
- 交通費節約: 早割・パック料金の具体例と節約額
- 宿泊費節約: 宿泊エリアの代替案
- 「節約分をどこに回すか」の提案まで出す

### Step 8: 予約・注意事項
- 事前予約が必要なもの一覧
- 混雑回避のポイント
- 公式で確認した拝観規制・マナー

## 出力フォーマット
1. **【最適な旅行時期の推薦】** — 具体的な日付範囲と根拠
2. 費用内訳（全体＋Day別）
3. Day別日程表（交通手段・路線番号・開館時間含む）
4. 予算節約コツ
5. 予約・注意事項
6. 参照ソース（公式サイトのURL）
