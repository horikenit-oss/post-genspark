# 旅行プランニングスキル

## トリガー
「〇〇旅行プラン」「〇〇に行きたい」「〇〇観光 おすすめ」+日程・人数・予算・出発地・テーマ

## 実行プロセス

### Step 1: 条件分解
- 目的地・出発地・日程（泊数）
- 人数・続柄（カップル・家族・友人等）
- 予算（交通費込み/別）
- テーマ（グルメ・自然・文化・アクティビティ等）
- 時期（混雑・気候・イベント）

### Step 2: 検索クエリ設計
1. `[目的地] [日程] [テーマ] おすすめ モデルコース [月・季節]`
2. `[出発地] [目的地] 交通手段 料金 [年]`
3. `[目的地] ホテル [予算帯] [時期] おすすめ`
4. `[目的地] 観光スポット [テーマ] おすすめ [年]`

### Step 3: 動線の最適化
- 地理的な移動順序（北→南、朝→夕の太陽向き等）
- 混雑を避ける時間帯（人気スポットは朝一または閉館前）
- 移動手段と所要時間を明記

### Step 4: 費用の内訳
| 項目 | 金額 | 備考 |
|------|------|------|
| 交通費（往復） | ¥X | [手段] |
| 宿泊費 | ¥X | ¥X/泊×泊数 |
| 食事 | ¥X | 1日¥X×日数 |
| 観光・入場料 | ¥X | 主要スポット合算 |
| **合計** | **¥X** | 予算¥Xに対して〇/✗ |

### Step 5: 日程表（Day別）
各Dayに:
- 午前: スポット名（移動手段・所要時間）
- 昼食: 店名またはエリア
- 午後: スポット名
- 夕食: 推薦ジャンル・エリア
- 宿泊: 宿泊エリア

### Step 6: 実用情報
- 予約が必要なものリスト
- 混雑回避のコツ
- 現地の移動手段（バス・電車・タクシー）

## 出力フォーマット
1. **【プラン概要】** — 一言で旅行のコンセプトを説明
2. 費用内訳（予算充足確認）
3. Day別日程表
4. 予約・注意事項
5. 参照ソース
